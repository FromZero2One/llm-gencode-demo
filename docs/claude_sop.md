# 📖 Claude Code 新功能开发标准作业程序 (SOP)

> **导言：** 本指南旨在规范使用 Claude Code 独立构建新功能时的生命周期管理。通过对 **规划、编码、测试、压缩、审计** 五个核心阶段的精密控制，在保障代码质量的同时，将 Token 消耗降至最低，彻底告别 Agent 长对话后的“记忆失控”与“无限死循环”。

---

## 🛑 阶段一：架构规划与契约固化（蓝图期）

* **目标：** 明确系统设计，严防 Agent 边写边猜。
* **最佳水位：** 初始状态（~5%）

### 1. 触发指令

在项目根目录启动 Claude Code 后，执行以下命令进入规划模式：

```bash
/plan 我们要开发 [新功能名称]。请帮我设计系统架构、接口契约（Interface/Types），并在根目录的 CLAUDE.md 中更新当前的活跃状态（Active Sprint）。

```

### 2. 核心原子动作

* **长考隔离：** `/plan` 模式会强制模型启动架构推理，避免其直接修改业务文件。
* **物理锚定：** 确保 Claude 将讨论出的关键文件清单、接口名称直接写入本地的 `CLAUDE.md`。

---

## 💻 阶段二：骨架开荒与代码填肉（编码期）

* **目标：** 批量生成干净、符合项目规范的底层脚手架。
* **最佳水位：** ~15%

### 1. 触发指令

明确指派任务，限制动作边界：

```bash
根据 CLAUDE.md 里的契约，帮我创建并实现 [具体文件路径1] 与 [具体文件路径2]。优先完成核心业务编排，如果需要引用未实现的第三方库，先列出占位符。

```

### 2. 工程规范

* **单次动作收窄：** 建议单次派发任务不超过 3 个关联文件，防止 AI 跨多目录大面积重构导致编译全面崩溃。

---

## 🧪 阶段三：自动化编译与故障自愈（验证期）

* **目标：** 利用本地工具链，让 AI 盯紧日志并在沙箱/本地闭环解 Bug。
* **最佳水位：** ~40%

### 1. 触发指令

向 Claude 授权执行终端校验指令：

```bash
/run npx tsc --noEmit && npm run test

```

### 2. 核心原子动作

* **错误拦截：** Claude Code 会自动捕获终端返回的 `stderr`（标准错误流）。
* **自愈编写：** AI 发现编译错误后，会再次主动调用 `edit_file` 工具修改代码，重复执行该步骤直至终端红条完全变绿（PASS）。

---

## ✂️ 阶段四：战略性记忆修剪（核心斩断点）

* **目标：** **清理海量垃圾终端日志，防止上下文腐烂（Context Rot）。**
* **触发时机：** **多轮调试后，当前窗口上下文水位达到 60% - 80% 之间。**

### 1. 触发指令

强制执行带精准条件的手动压缩：

```bash
/compact 重点保留刚才新建的 [核心核心文件/类名] 的完整业务逻辑与接口契约；保留我们关于 [某项关键技术决定] 的决策原因；彻底擦除前文长达几百行的终端编译与测试日志。

```

### 2. 深度避坑原则

> ⚠️ **严禁闭眼执行裸命令**
> 绝对不要只输入无参数的 `/compact`。必须在命令后追加你**绝对不能让它忘掉的死路（Rejected Paths）或硬核数据**，否则多轮压缩后，AI 会出现渐进式失忆。

---

## 🕵️ 阶段五：左右脑互博与对抗性找茬（审计期）

* **目标：** 压榨大模型深度推理极限，阻击高并发、死锁等逻辑死角。
* **最佳水位：** ~25%（压缩复位后）

### 1. 触发指令

1. 在终端键盘上按下 **`Alt+T`**（或者在输入框中使用 `--thinking` 标志），拉满 Claude 的 **Extended Thinking（深度思考）**。
2. 输入代码审查指令：

```bash
/code-review --comment 对抗性审查当前的 [核心业务文件路径]。站在骨灰级架构师的视角，挑刺并发场景下的漏洞（如缓存击穿、竞态条件、内存泄露），并直接给出修复补丁。

```

### 2. 核心原子动作

* **红蓝对抗：** 在深度推理加持下，Claude 会开启自审逻辑，模拟攻击者视角对刚写完的新功能进行极端压力测试，并自动在本地打上防御性代码补丁。

---

## 📦 阶段六：状态对齐与规范归档（交付期）

* **目标：** 清理现场，平稳交付 Git 树。

### 1. 触发指令

```bash
更新 CLAUDE.md 中的 Active Sprint，将该新功能标记为已完成。然后帮我生成一条符合 Conventional Commits 规范的 git commit 提交信息。

```

## 🛠️ Claude Code 开荒核心命令速查表

| 指令 | 武器库定位 | 核心心法 |
| --- | --- | --- |
| **`/plan`** | 战术沙盘 | 一行代码不写时用。确保本地 `CLAUDE.md` 成为唯一的 Source of Truth。 |
| **`/run <cmd>`** | 终端触手 | 验证单测、Lint 或编译。让 AI 盯着黑窗口自己碰壁、自己修正。 |
| **`/compact`** | **生存技能** | **水位卡在 60% - 80% 必用。追加清晰保留参数，人工斩断垃圾历史。** |
| **`/code-review`** | 终极大闸 | 必须配合 `Alt+T`（深度思考）。不要让写代码的脑子去审代码。 |
