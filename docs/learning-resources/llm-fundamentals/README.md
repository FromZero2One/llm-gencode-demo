## 📖 教程结构

本教程分为三个部分,建议按顺序阅读:

### [第一部分:基础概念](BEGINNER_TUTORIAL_PART1.md)
**阅读时间**: 60-90分钟 | **1373行**

包含5个章节:
1. Tokenization(文本→数字)
2. Embedding(让机器"看见"文字)
3. Positional Encoding(告诉模型顺序)
4. **Attention机制**(⭐核心章节,最详细)
5. Multi-Head Attention(多视角学习)

**重点**: 第4章Attention机制是整个教程的核心,请花足够时间理解!

---

### [第二部分:架构与生成](BEGINNER_TUTORIAL_PART2.md)
**阅读时间**: 45-60分钟 | **873行**

包含5个章节:
6. Encoder(理解输入)
7. Decoder(生成输出)
8. 完整的Transformer架构
9. 自回归生成
10. 采样策略(Temperature & Top-K)

**重点**: 理解Encoder-Decoder的数据流和自回归生成机制

---

### [第三部分:优化与实践](BEGINNER_TUTORIAL_PART3.md)
**阅读时间**: 30-45分钟 | **937行**

包含4个章节:
11. KV Cache性能优化(50倍加速!)
12. 后处理(Post-processing)
13. 完整流程总结
14. 附录:实战练习与常见问题(15+道题)

**重点**: KV Cache是实用的性能优化技术,强烈建议掌握
