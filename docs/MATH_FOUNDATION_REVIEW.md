#### 1.3.X 矩阵的迹（Trace）

**定义**：
```
tr(A) = Σᵢ A[i,i]  （对角线元素之和）
```

**重要性质**：
- tr(AB) = tr(BA)
- tr(A + B) = tr(A) + tr(B)
- tr(A) = tr(A^T)

**在深度学习中的应用**：
```python
# Frobenius范数的平方等于迹
||A||_F² = tr(A^T A)
```
```

**缺失3：广播机制（Broadcasting）**

- **建议添加位置**: 1.2 矩阵运算之后新增小节

```markdown
#### 1.2.X 广播机制（Broadcasting）

**规则**：
1. 从后往前比较维度
2. 如果维度相等或其中一个为1，则可以广播
3. 输出维度取最大值

**示例**：
```
A: (3, 4, 5)
B: (4, 1)
结果: (3, 4, 5)  # B被广播到(3, 4, 5)
```

**在Transformer中的应用**：
```python
# 位置编码加到embedding上
embedding: (batch, seq_len, d_model)
pos_encoding: (1, seq_len, d_model)  # 广播到所有batch
result: (batch, seq_len, d_model)
```
```

**缺失4：Jacobian矩阵和Hessian矩阵**

- **建议添加位置**: 2.2 多元函数与偏导数之后

```markdown
#### 2.2.X Jacobian和Hessian矩阵

**Jacobian矩阵**：
对于 f: Rⁿ → Rᵐ，Jacobian是 m×n 矩阵：
```
J[i,j] = ∂f_i/∂x_j
```

**Hessian矩阵**：
对于 f: Rⁿ → R，Hessian是 n×n 矩阵：
```
H[i,j] = ∂²f/∂x_i∂x_j
```

**意义**：
- Jacobian：一阶导数的推广
- Hessian：二阶导数，描述函数的曲率

**在深度学习中的应用**：
- Hessian用于二阶优化方法（如Newton法）
- 判断临界点是极小值、极大值还是鞍点
```

#### 3.2.X 最大似然估计（MLE）

**思想**：选择使观测数据出现概率最大的参数

**公式**：
```
θ_MLE = argmax_θ P(Data | θ)
      = argmax_θ Σ log P(x_i | θ)
```

**在语言模型中的应用**：
```
训练目标：最大化语料库的对数似然
L = Σ log P(token_i | context)
```

**与交叉熵的关系**：
最小化交叉熵等价于最大化似然
```

```markdown
#### 4.0 凸优化基础

**凸函数定义**：
```
f(λx + (1-λ)y) ≤ λf(x) + (1-λ)f(y),  ∀λ∈[0,1]
```

**性质**：
- 局部最优 = 全局最优
- 梯度为0的点是最优解

**深度学习的非凸性**：
- 神经网络损失函数是非凸的
- 但实践中仍能找到好的局部最优
- 原因：高维空间中 saddle point 比 local minimum 更常见

```markdown
### X.X 数值稳定性

**问题1：Softmax溢出**
```python
# 错误实现
def softmax(x):
    return np.exp(x) / np.sum(np.exp(x))  # 可能溢出

# 正确实现
def stable_softmax(x):
    x_max = np.max(x)
    return np.exp(x - x_max) / np.sum(np.exp(x - x_max))
```

**问题2：Log下溢**
```python
# 当p很小时，log(p)会下溢
# 解决方案：使用 log-sum-exp trick
log_sum_exp(x) = max(x) + log(sum(exp(x - max(x))))
```

**问题3：梯度消失/爆炸**
- 原因：连乘导致指数级变化
- 解决：残差连接、LayerNorm、梯度裁剪
```
